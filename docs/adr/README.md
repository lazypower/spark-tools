# Architecture Decision Records

Short, durable records of significant architecture decisions — the *why* behind a
direction, captured at the moment it's taken so future readers (and models)
don't re-litigate it from scratch.

Format: one file per decision, `NNNN-kebab-title.md`, with a `**Status:**`
(Proposed → Accepted → Superseded) and a `**Created:**` date. Keep them tight:
Context, Decision, Consequences, Alternatives. An ADR records a decision; a full
component design lives in `specs/`.
